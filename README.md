# PhonePe Transaction Analytics Dashboard

## 📊 Project Overview
Analyzed **5,00,000 rows × 22 columns** of PhonePe transaction data using **MS Excel & Julius AI** to track business performance, success rate, cashback, and fraud.

## 🎯 Key Results
- **Total Transactions:** 5,02,887
- **Total Amount:** ₹44.25 Cr
- **Total Cashback:** ₹34.63 L
- **Success Rate:** 91%
- **Suspected Fraud:** 17,089 (3.4%)
- **Failed / Pending:** 9%

## 🛠️ What I Did
1. **Data Cleaning in Excel** - Removed duplicates, fixed Date/Time formats, handled nulls, standardized Bank, Merchant, Status, Transaction Type
2. **Pivot Tables & Pivot Charts** - Created pivots for State, Bank, App, Merchant Category, Hour, Day
3. **Dashboard in Excel** - Built KPI cards, slicers, India Map, Donut Charts, Bar Charts, Day-Hour Heatmap
4. **Analysis in Julius AI** - Uploaded cleaned Excel, asked for trends, fraud patterns, peak hours, top merchants
5. **Insights** - Found peak transaction hours, top banks, high fraud merchants, and failed transaction patterns
